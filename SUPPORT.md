# Support

Local Media Proxy is an open-source, community-supported project maintained by Amsive LLC.

## Community support

Use [GitHub Issues](https://github.com/amsive/local-media-proxy/issues) for reproducible bugs and focused feature requests. Maintainers review reports on a best-effort basis. Opening an issue does not create a service-level agreement, support commitment, warranty, or obligation to provide a fix or response within a particular timeframe.

Before reporting a problem, test the latest release and include the Local version, host connection type, site web server, sanitized reproduction steps, and expected behavior. Do not include client data, credentials, private certificates, access tokens, cookies, or production secrets.

## Security reports

Do not report suspected vulnerabilities in a public issue. Follow [SECURITY.md](SECURITY.md) to submit them confidentially.
